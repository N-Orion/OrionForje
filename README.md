# ⚒️ OrionForge

**OrionForge** é uma ferramenta gratuita para mestres de RPG criarem conteúdo rapidamente para suas campanhas.

## ✨ Recursos

- 🎲 Gerador de NPCs
- 📜 Missões curtas
- 🗺️ Missões longas
- 🌍 Gerador de regiões e cidades
- ✨ Itens mágicos
- 🧩 Puzzles
- 🎭 Regras da casa
- 💾 Histórico local de conteúdo gerado

## 🖥️ Tecnologias

- HTML5
- CSS3
- JavaScript puro

## 🚀 Objetivo

Criar uma experiência simples, rápida e imersiva para improvisação e preparação de sessões de RPG.
